# The Reliquary Vault

A short **field guide** to what's kept behind glass, written for anyone who
wonders *why* the light in here never quite settles.

## Contents

- Amethyst, for keywords and control flow
- Sapphire, for function calls
- Emerald, for strings
- Teal, for types and classes
- Garnet / Ruby, for errors and tags

> Nothing in the vault is decorative. Every color earns its place.

### Cataloguing a gem

Run the appraisal script against a single entry:

```python
appraise(Gem(name="Sapphire", hex="#6FB3E0", weight_carats=4.2))
```

| Gem | Hex | Category |
| --- | --- | --- |
| Amethyst | `#B27EE8` | Keywords |
| Sapphire | `#6FB3E0` | Function calls |
| Emerald | `#3EE0A0` | Strings |

See the [Reliquary README](../README.md) for the full palette table.
